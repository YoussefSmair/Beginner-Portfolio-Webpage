This project is a simple front-end portfolio website created during my early learning phase in web development. It consists of multiple static pages such as Home, About, Contact, and Portfolio, all styled with basic HTML and CSS, with minimal JavaScript used for simple interactions. The main purpose of this project is to practice building website layouts, organizing files, and understanding how static websites are structured.
Although the design and structure are beginner-level, this project represents an important foundational step in my learning journey, helping me get comfortable with front-end development and preparing me for more advanced projects in the future.
